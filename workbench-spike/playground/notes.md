# Calc Module Functions

## add(a, b)
Basic function that returns the sum of two numbers.

## mean(xs)
Calculates the arithmetic mean of a list of numbers. Validates that the input list is not empty and raises ValueError if empty. Returns a float.

## median(xs)
Calculates the median value of a list of numbers by sorting and finding the middle value. Handles both odd and even-length lists. Returns a float.

## Demo
The module includes a `__main__` block that demonstrates both mean and median functions on a sample list [1, 2, 3, 4, 5].
